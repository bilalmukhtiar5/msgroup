# MS Group React + Tailwind Demo

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Structure

- Home hero
- Fixed responsive navbar
- 8 service cards
- About / capability section
- Detailed service sections for all 8 categories
- CTA / contact section
- Responsive mobile menu
- MS Group logo included in `public/ms-group-logo.png`

This first demo intentionally keeps the visual language focused on the supplied logo:
- Deep black
- MS Group red
- White
- Minimal borders
- Large typography
- Rounded cards
